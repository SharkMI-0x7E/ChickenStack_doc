# 栈操作示例

栈是 ChickenStack 的核心数据结构。本示例展示各种栈操作的用法，包括复制、交换和丢弃。

## 基本栈操作

### 复制 (:)

**功能**: 复制栈顶元素

```ch
# 基本复制: 输出 5 5
5 : . .
10 "   # 换行，让两段输出分开显示

# 多次复制: : 只是多留一份，要打印 4 个就得写 4 个 .
10 : : : . . . .
```

**输出**:
```
5 5
10 10 10 10
```

**执行过程**:
```
5 : . .
↓
推入 5 → 栈: [5]
复制 → 栈: [5, 5]
打印 → 输出 5, 栈: [5]
打印 → 输出 5, 栈: []
```

### 交换 (\)

**功能**: 交换栈顶两个元素

```ch
# 基本交换: 用对操作数顺序敏感的减法来观察
5 3 - .      # 不交换: 5 - 3 = 2
10 "         # 换行
5 3 \ - .    # 交换后: 3 - 5 = -2
```

**输出**:
```
2
-2
```

**执行过程**:
```
5 3 \ - .
↓
推入 5 → 栈: [5]
推入 3 → 栈: [5, 3]
交换 → 栈: [3, 5]
减法 → 栈: [-2]
打印 → 输出 -2, 栈: []
```

直接打印栈内元素看不出交换效果：`.` 会弹出栈顶，连续打印的顺序正好又把栈倒了一次。判断交换是否生效，要用减法、除法这类对操作数顺序敏感的运算。

### 丢弃 ($)

**功能**: 丢弃栈顶元素

```ch
# 基本丢弃: 输出 10
10 20 $ .
10 "   # 换行

# 多次丢弃: 输出 1
1 2 3 4 $ $ $ .
```

**输出**:
```
10
1
```

**执行过程**:
```
10 20 $ .
↓
推入 10 → 栈: [10]
推入 20 → 栈: [10, 20]
丢弃 → 栈: [10]
打印 → 输出 10, 栈: []
```

## 组合操作

### 示例1: 保存中间结果

```ch
# 计算 (5 + 3) * 2 = 16
# 使用复制保存中间结果
5 3 + : 2 * .
```

**输出**:
```
16
```

**执行过程**:
```
5 3 + : 2 * .
↓
推入 5 → 栈: [5]
推入 3 → 栈: [5, 3]
加法 → 栈: [8]
复制 → 栈: [8, 8]
推入 2 → 栈: [8, 8, 2]
乘法 → 栈: [8, 16]
打印 → 输出 16, 栈: [8]
```

### 示例2: 重复使用值

```ch
# 使用同一个值多次
5 : 2 * : 3 * . .
```

**输出**:
```
30 10
```

**执行过程**:
```
5 : 2 * : 3 * . .
↓
推入 5 → 栈: [5]
复制 → 栈: [5, 5]
推入 2 → 栈: [5, 5, 2]
乘法 → 栈: [5, 10]
复制 → 栈: [5, 10, 10]
推入 3 → 栈: [5, 10, 10, 3]
乘法 → 栈: [5, 10, 30]
打印 → 输出 30, 栈: [5, 10]
打印 → 输出 10, 栈: [5]
```

### 示例3: 交换运算顺序

```ch
# 计算 3 - 5 (而不是 5 - 3)
5 3 \ - .
```

**输出**:
```
-2
```

**执行过程**:
```
5 3 \ - .
↓
推入 5 → 栈: [5]
推入 3 → 栈: [5, 3]
交换 → 栈: [3, 5]
减法 → 栈: [-2]
打印 → 输出 -2, 栈: []
```

### 示例4: 清理栈

```ch
# 清理不需要的中间结果
5 3 + 10 20 + $ .
```

**输出**:
```
8
```

**执行过程**:
```
5 3 + 10 20 + $ .
↓
推入 5 → 栈: [5]
推入 3 → 栈: [5, 3]
加法 → 栈: [8]
推入 10 → 栈: [8, 10]
推入 20 → 栈: [8, 10, 20]
加法 → 栈: [8, 30]
丢弃 → 栈: [8]
打印 → 输出 8, 栈: []
```

## 高级栈操作

### 示例1: 旋转栈元素

```ch
# @ 旋转栈顶三个: [a, b, c] → [b, c, a]
1 2 3 @ . . .
```

**输出**:
```
1 3 2
```

执行后栈内是 `[2, 3, 1]`。打印从栈顶开始，所以输出顺序与栈内顺序相反。

### 示例2: 深度复制

```ch
# ! 按深度复制: 先弹出深度 n，再复制往下第 n 个元素
1 2 3 2 ! . . . .
```

**输出**:
```
1 3 2 1
```

深度 2 取到的是 1，复制后栈变为 `[1, 2, 3, 1]`，原栈内容不受影响。

### 示例3: 栈反转

```ch
# 栈反转: 用寄存器按相反顺序读出
1 A 2 B 3 C 4 D d . c . b . a .
```

**输出**:
```
4 3 2 1
```

没有任何单个指令能反转整栈，`\` 只管栈顶两个，元素多了就得靠寄存器显式倒序读取。

### 示例4: 借助寄存器交换

```ch
# 交换栈顶两个值: [1, 2] → [2, 1]
1 A 2 B b . a .
```

**输出**:
```
2 1
```

两个值先各自存入寄存器，再按交换后的顺序读回，比连续 `\` 更容易看清意图。

## 实际应用

### 示例1: 计算最大值

```ch
# 找出 10 和 20 的最大值
10 20 > { 10 . | 20 . }
```

**输出**:
```
20
```

**执行过程**:
```
10 20 > → 判断 10 > 20，结果 0，栈 = [0]
{ → 弹出 0，执行 else 分支
20 . → 输出 20，栈 = []
```

### 示例2: 计算最小值

```ch
# 找出 10 和 20 的最小值
10 20 > { 20 . | 10 . }
```

**输出**:
```
10
```

### 示例3: 三元运算符

```ch
# 模拟 condition ? a : b
# { 弹出条件，非 0 走 then，0 走 else
1 { 10 . | 20 . }   # 条件为真，输出 10
0 { 10 . | 20 . }   # 条件为假，输出 20
```

**输出**:
```
10 20
```

### 示例4: 保存和恢复

```ch
# 复制一份参与计算，原值留在栈底，最后打印原值
5 : 3 + $ .   # 输出 5
```

**输出**:
```
5
```

### 示例5: 分发值

```ch
# 把一个值分发到多个计算: 5*2、5*3、5*4
5 A 2 a * . 3 a * . 4 a * .
```

**输出**:
```
10 15 20
```

## 栈操作与循环

### 示例1: 循环中使用复制

```ch
# 从 5 倒数到 1
5 [ : . 1 - ]
```

**输出**:
```
5 4 3 2 1
```

### 示例2: 循环累加

```ch
# 计算 1+2+3+4+5 = 15
# 累加器必须放寄存器，栈顶留给循环条件
# 每轮末尾把 a <= 5 的比较结果压栈，供下一轮 [ 检查
0 T 1 A 5 [ t a + T a 1 + A a 5 > 0 = ] t .
```

**输出**:
```
15
```

`a 5 > 0 =` 是「不大于 5」的写法，语言只提供 `=` 和 `>`，取反要借 0 比较。

### 示例3: 循环乘法

```ch
# 计算 1*2*3*4*5 = 120
# 与累加同构，只把 + 换成 *
1 T 1 A 5 [ t a * T a 1 + A a 5 > 0 = ] t .
```

**输出**:
```
120
```

### 示例4: 嵌套循环

```ch
# 打印 3x3 矩阵，每行 5 4 3 2 1
# 内层循环结束后计数减到 0，用 $ 清掉再换行，否则外层 1 - 会作用在 0 上
3 [ 5 [ : . 1 - ] $ 10 " 1 - ]
```

**输出**:
```
5 4 3 2 1
5 4 3 2 1
5 4 3 2 1
```

## 使用 Python API

### 示例1: 基本栈操作

```python
from chicken_stack import ChickenStackVM

vm = ChickenStackVM()

# 推入数据
vm.push(10)
vm.push(20)
print(vm.get_stack_state())  # [10, 20]

# 复制
vm.op_dup()
print(vm.get_stack_state())  # [10, 20, 20]

# 交换
vm.op_swap()   # 交换栈顶两个，此时两份都是 20，栈不变
print(vm.get_stack_state())  # [10, 20, 20]

# 丢弃
vm.op_drop()
print(vm.get_stack_state())  # [10, 20]
```

### 示例2: 查看栈状态

```python
from chicken_stack import ChickenStackVM

vm = ChickenStackVM()

# 推入数据
vm.push(10)
vm.push(20)
vm.push(30)

# 查看栈顶
print(vm.peek())  # 30

# 获取栈状态
print(vm.get_stack_state())  # [10, 20, 30]

# 弹出元素
value = vm.pop()
print(value)  # 30
print(vm.get_stack_state())  # [10, 20]
```

### 示例3: 自定义栈操作

```python
from chicken_stack import ChickenStackVM

class ExtendedVM(ChickenStackVM):
    def op_rotate3(self):
        """旋转栈顶三个元素: [a, b, c] → [b, c, a]"""
        self._require_stack(3)
        c = self.pop()
        b = self.pop()
        a = self.pop()
        self.push(b)
        self.push(c)
        self.push(a)

# 使用扩展虚拟机
vm = ExtendedVM()
vm.push(1)
vm.push(2)
vm.push(3)
vm.op_rotate3()
print(vm.get_stack_state())  # [2, 3, 1]
```

### 技巧1: 打印栈状态

```ch
# 在关键位置打印栈顶: 输出 5 8
5 : .   # 复制一份打印，原值留在栈上
3 + .
```

**输出**:
```

```

### 技巧2: 使用复制检查

```ch
# 使用复制来检查中间结果
5 3 + : .  # 8
2 * : .    # 16
5 - .      # 11
```

### 技巧3: 逐步执行

```python
from chicken_stack import ChickenStackVM

class DebugVM(ChickenStackVM):
    def push(self, value):
        print(f"推入 {value}")
        super().push(value)
        print(f"栈: {self.get_stack_state()}")

    def op_dup(self):
        print("复制栈顶")
        super().op_dup()
        print(f"栈: {self.get_stack_state()}")

    def op_swap(self):
        print("交换栈顶")
        super().op_swap()
        print(f"栈: {self.get_stack_state()}")

    def op_drop(self):
        print("丢弃栈顶")
        super().op_drop()
        print(f"栈: {self.get_stack_state()}")

# 使用调试虚拟机
vm = DebugVM()
vm.push(5)
vm.op_dup()
vm.op_print_num()
```

## 性能优化

### 技巧1: 减少不必要的复制

```ch
# 优化前: 复制了两次，栈里还留着中间值 5
5 : 3 + : 2 * .

# 优化后: 只在需要保留结果时才复制
5 3 + 2 * .
```

两段都输出 16，区别在于优化前执行完栈里还剩一个 5。

### 技巧2: 合并操作

```ch
# 优化前: 重复压入同一个字面量，输出 5 5
5 : . 5 : .

# 优化后: 一次压栈、连续复制，输出 5 5
5 : : . .
```

### 技巧3: 及时清理

```ch
# 优化前: 栈顶是 30，把之前的结果盖在下面，最后只能打印 30
5 3 + 10 20 + .

# 优化后: 先丢弃不要的中间结果，再打印 8
5 3 + 10 20 + $ .
```

## 常见错误

### 错误1: 栈空操作

```ch
# 错误: 栈为空时复制
: .

# 正确: 先推入数据
5 : .
```

### 错误2: 栈元素不足

```ch
# 错误: 栈元素不足交换
5 \ .

# 正确: 至少两个元素
5 10 \ .
```

### 错误3: 操作顺序错误

```ch
# 错误理解: 以为 \ 能一次调整多个元素的位置
1 2 3 \ . . .   # 实际只交换栈顶两个，输出 2 3 1

# 正确: 需要倒序时用寄存器按目标顺序读出
1 A 2 B 3 C c . b . a .
```

## 栈操作模式

### 模式1: 保存-使用-恢复

```ch
# 保存-使用-恢复: 复制一份参与计算，最后打印原值
5 : 3 + $ .   # 输出 5
```

### 模式2: 交换-计算

```ch
# 交换-计算: 交换后栈顶是左操作数，所以算的是 3 - 5
5 3 \ - .   # 输出 -2
```

### 模式3: 复制-分发

```ch
# 复制-分发: 一个值参与多个计算
5 A 2 a * . 3 a * .   # 输出 10 15
```

### 模式4: 清理-重用

```ch
# 清理-重用: 丢掉旧值，只留新值
1 2 3 $ $ 9 .   # 输出 9
```

## 总结

栈操作是 ChickenStack 的基础：

1. **复制**: 重复使用栈顶值
2. **交换**: 调整运算顺序
3. **丢弃**: 清理不需要的值
4. **组合**: 实现复杂逻辑

- 掌握栈操作技巧
